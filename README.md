# Santa Clara County Permit Review Assistant: AI for Building Permit Review

Client: Santa Clara County, Department of Planning and Development

Team: Ivan Barrera Rivera, Alondra Campos, Belinda Flores, Luis Garcia, Alija Gacanovic

My part: I helped build and refine the applicant intake flow, jurisdiction validation, TRACE red-team testing, and the application records page.

## The problem

Santa Clara County receives a high volume of building permit applications, and manual review can slow down feedback, create bottlenecks, and delay housing development.

County staff can spend time sorting incomplete, inconsistent, or misrouted applications before meaningful review can begin. This can increase workload for staff and delay feedback for builders and contractors.

## What we built

- Built an AI-assisted permit review prototype that pre-screens building permit applications for missing information, completeness, and potential issues.
- Created separate applicant and County staff views so builders can submit and track applications while staff can review organized records, flags, and priority labels.
- Added features for document-status checks, Santa Clara County address validation, application routing, persistent records, and human review before final decisions.

## What I would do next

One gap we found was that the system could still miss inconsistencies between application fields, such as a project type that did not match the project description or housing-unit count.

Next, I would improve the prototype by adding stronger validation rules, verified jurisdiction data, and a more reliable escalation workflow that assigns questionable applications to a County reviewer instead of only displaying a warning.
